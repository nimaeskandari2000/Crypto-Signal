# 🤖 ربات سیگنال‌دهی و مدیریت کوانت QuantPulse (نسخه ویژه GitHub Actions و GitHub Pages)

سامانه هوشمند و بدون نیاز به سرور (**Serverless**) برای تحلیل و سیگنال‌دهی لحظه‌ای بازار **کریپتو**، **شکارچی پامپ (High-Pump Radar)**، **توکن‌های فارکس و سهام جهانی (RWA)**، و **تحلیل ۳ افق زمانی دلار و طلا** با اتصال مستقیم به فید زنده **والکس، بیت‌پین، کراکن و یاهو فایننس** (بدون نیاز به هیچ API Key پولی).

---

## 🚀 راهنمای ۳ دقیقه‌ای آپلود فایل ZIP در گیت‌هاب و فعال‌سازی ربات

پس از دانلود پروژه به صورت فایل **ZIP** و خارج کردن آن از حالت فشرده (Extract):

### گام ۱: ساخت ریپازیتوری و آپلود فایل‌ها
1. وارد اکانت GitHub خود شوید و یک Repository جدید (مثلاً با نام `quantpulse`) بسازید.
2. تمامی فایل‌ها و پوشه‌های داخل ZIP (شامل پوشه مخفی `.github`، `src`، `scripts`، `public`، `package.json` و غیره) را در ریپازیتوری خود آپلود یا Push کنید.
   > **نکته مهم:** دقت کنید پوشه `.github/workflows` حتماً آپلود شود چون موتور اجرای خودکار ۱۵ دقیقه‌ای و گزارش روزانه داخل آن قرار دارد.

### گام ۲: ثبت توکن تلگرام در GitHub Secrets
برای اینکه GitHub Actions بتواند سیگنال‌ها و گزارش‌های روزانه را به تلگرام شما بفرستد:
1. در صفحه ریپازیتوری گیت‌هاب خود به تب **Settings** بروید.
2. از منوی سمت چپ، گزینه **Secrets and variables** ⬅️ **Actions** را انتخاب کنید.
3. روی دکمه سبز **New repository secret** کلیک کنید و این ۲ متغیر را بسازید:
   - **`TELEGRAM_BOT_TOKEN`**: توکن ربات تلگرام دریافتی از `@BotFather`
   - **`TELEGRAM_CHAT_ID`**: شناسه عددی چت یا کانال تلگرام شما (مثلاً `72594978`)

### گام ۳: فعال‌سازی داشبورد وب رایگان روی GitHub Pages
1. در همان بخش **Settings** ریپازیتوری، از منوی سمت چپ وارد بخش **Pages** شوید.
2. در قسمت **Build and deployment**، گزینه **Source** را از حالت `Deploy from a branch` به **`GitHub Actions`** تغییر دهید.
3. همچنین در بخش **Settings** ⬅️ **Actions** ⬅️ **General**، در قسمت **Workflow permissions** گزینه **`Read and write permissions`** را تیک بزنید و Save کنید.

## ⏱ زمان‌بندی اجرای خودکار در GitHub Actions

| ورک‌فلو (Workflow) | فایل مربوطه | زمان اجرا | وظیفه |
| :--- | :--- | :--- | :--- |
| **اسکن جامع و پایش قفل سیگنال** | `.github/workflows/scan.yml` | هر ۱۵ دقیقه (`*/15 * * * *`) + هنگام Push | دریافت قیمت‌های زنده والکس/کراکن/یاهو، بروزرسانی سیگنال‌ها، پایش سیگنال‌های قفل‌شده (`🔒`)، ارسال به تلگرام و آپدیت خودکار داشبورد GitHub Pages |
| **بولتن روزانه دلار، طلا و کارنامه** | `.github/workflows/daily.yml` | هر روز ساعت ۰۸:۰۰ صبح تهران (`30 4 * * *`) | ارسال تحلیل تکنیکال و فاندامنتال کوتاه‌مدت، میان‌مدت و بلندمدت دلار و طلا + کارنامه نرخ برد (Win Rate) به تلگرام |
| **کالبدشکافی و کالیبراسیون هفتگی** | `.github/workflows/weekly.yml` | شنبه‌ها ساعت ۰۸:۰۰ صبح تهران (`30 4 * * 6`) | بررسی عملکرد استراتژی‌ها، کلید قطع خودکار (Circuit Breaker) و گزارش قهرمان/رقیب |

> **تشخیص خودکار لینک داشبورد:** به محض اجرای ربات در GitHub Actions، لینک پایین پیام‌های تلگرام به صورت خودکار به آدرس GitHub Pages ریپازیتوری شما (`https://<username>.github.io/<repo>/`) تبدیل می‌شود و نیازی به ویرایش دستی کد نیست.

## 💻 اجرای محلی (روی کامپیوتر شخصی یا سرور)

```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. کپی فایل تنظیمات محیطی و قرار دادن توکن تلگرام
cp .env.example .env

# ۳. اجرای همزمان سرور و کنسول وب روی پورت 3000
npm run dev

# ۴. اجرای دستی اسکن زنده یا گزارش روزانه
npm run scan
npm run daily
npm run test
```
